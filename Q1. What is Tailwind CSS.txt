Q1. What is Tailwind CSS?

Answer:

Tailwind CSS is a utility-first CSS framework that allows us to build responsive UIs using utility classes directly in JSX.

Q2. How is Tailwind different from Bootstrap?

Answer:

Bootstrap provides pre-built components, while Tailwind provides low-level utility classes that give more design control.

Q3. What does utility-first mean?

Answer:

It means using small, reusable classes like p-4, text-center, and bg-blue-500 to build UI.

Q4. How do you integrate Tailwind with React?

Answer:

By installing Tailwind via npm, configuring tailwind.config.js, adding Tailwind directives in CSS, and using utility classes inside JSX.

Q5. Explain Tailwind breakpoints.

Answer:

Tailwind uses mobile-first breakpoints like sm, md, lg, where styles apply from that screen size and above.

Q6. How do you make a layout responsive in Tailwind?

Answer:

By using breakpoint prefixes like md:grid-cols-2 or lg:flex-row.

Q7. What is mobile-first design?

Answer:

Designing for mobile first and then enhancing the UI for larger screens using breakpoints.

Q8. How do you handle hover and focus?

Answer:

Using variants like hover:bg-blue-600 and focus:ring-2.

Q9. How do you customize Tailwind styles?

Answer:

By extending the theme inside tailwind.config.js.

Q10. Why is Tailwind good for React projects?

Answer:

It works well with component-based architecture and avoids CSS conflicts.
1️⃣ What is an API?

Answer:

An API (Application Programming Interface) is a set of rules that allows two applications to communicate with each other.

Simple Example

Frontend sends request

Backend sends response

2️⃣ What is a REST API?

Answer:

A REST API is an API that follows REST principles and uses HTTP methods to perform CRUD operations.

3️⃣ What does REST stand for?

Answer:

REST stands for Representational State Transfer.

4️⃣ What is client and server?

Answer:

Client → Frontend (React)

Server → Backend (Node.js + Express)

Client sends request, server returns response

5️⃣ What format is commonly used in APIs?

Answer:

JSON (JavaScript Object Notation) is the most commonly used data format.

🟢 HTTP METHODS (VERY IMPORTANT)
6️⃣ What are HTTP methods?

Answer:

HTTP methods define the type of operation to be performed on data.

Method	Purpose
GET	Fetch data
POST	Create data
PUT	Update entire data
PATCH	Update partial data
DELETE	Delete data
7️⃣ Difference between PUT and PATCH?

Answer:

PUT → Updates full resource

PATCH → Updates specific fields only

8️⃣ Can GET have a body?

Answer:

No, GET requests do not have a request body. Data is passed via query parameters.

🟢 REQUEST & RESPONSE
9️⃣ What is an API request?

Answer:

An API request is sent by the client containing URL, method, headers, and optional body.

🔟 What is an API response?

Answer:

An API response is sent by the server containing status code, headers, and response data.

1️⃣1️⃣ What is request body?

Answer:

Data sent from client to server, usually in POST or PUT requests.

1️⃣2️⃣ What are headers?

Answer:

Headers contain metadata like content type, authorization token, etc.

1️⃣ What is authentication?

Answer:

Authentication is the process of verifying a user’s identity, usually using login credentials like email and password.

2️⃣ What is authorization?

Answer:

Authorization determines what actions or resources an authenticated user is allowed to access.

3️⃣ Difference between authentication and authorization?

Answer:

Authentication → Who are you?

Authorization → What are you allowed to do?

4️⃣ What is an auth token?

Answer:

An auth token is a secure string issued by the server after login that proves the user is authenticated and is sent with every protected request.

5️⃣ Why do we need auth tokens?

Answer:

To avoid sending username and password on every request and to securely access protected APIs.

🟢 JWT (JSON WEB TOKEN)
6️⃣ What is JWT?

Answer:

JWT (JSON Web Token) is a compact, secure token used to transmit user information between client and server.

7️⃣ Why is JWT commonly used in MERN?

Answer:

Stateless authentication

Works well with REST APIs

Easy to use with React and Express

Scales well

8️⃣ What are the parts of a JWT?

Answer:
JWT has three parts:

Header

Payload

Signature

Format:

header.payload.signature

9️⃣ What is stored in JWT payload?

Answer:

User-related information like userId, email, role (never passwords).

🔟 What is JWT signature?

Answer:

The signature ensures that the token is not tampered with and is created using a secret key.

🟢 JWT AUTH FLOW (VERY IMPORTANT)
1️⃣1️⃣ Explain JWT authentication flow.

Answer:

User logs in with credentials

Server verifies credentials

Server generates JWT

JWT is sent to client

Client stores JWT

Client sends JWT with every request

Server verifies JWT before allowing access

1️⃣2️⃣ Where do you store JWT on frontend?

Answer:

localStorage

sessionStorage

cookies (httpOnly preferred)

1️⃣3️⃣ Which is more secure: localStorage or cookies?

Answer:

Cookies with httpOnly flag are more secure because they are not accessible via JavaScript.

🟢 JWT IN NODE & EXPRESS

1️⃣6️⃣ What is auth middleware?

Answer:

A middleware that checks the token, verifies it, and allows or blocks access to protected routes.

1️⃣7️⃣ Where is token sent from frontend?

Answer:

Fetch	Axios

Users access apps on different devices

Improves accessibility

Required for modern web applications

Answer:

Tailwind provides built-in responsive utility classes using breakpoint prefixes like sm, md, lg, which make responsiveness easy without writing media queries.

🟢 TAILWIND BREAKPOINTS (MUST MEMORIZE)
4️⃣ What are Tailwind default breakpoints?

Answer:

Prefix	Min Width

md:	768px
lg:	1024px
xl:	1280px

5️⃣ What does md: mean in Tailwind?

Answer:

md: means the styles will apply when the screen width is 768px or above.

🟢 MOBILE-FIRST DESIGN (VERY IMPORTANT)
6️⃣ What is mobile-first design?

Answer:

Mobile-first design means writing default styles for mobile devices first, then adding styles for larger screens using breakpoints.

7️⃣ Does Tailwind follow mobile-first approach?

Answer:

Yes, Tailwind is mobile-first by default.

8️⃣ Explain mobile-first with an example.
<p className="text-sm md:text-lg lg:text-xl">
  Responsive Text
</p>


Explanation:

Mobile → text-sm

Tablet → md:text-lg

Desktop → lg:text-xl

9️⃣ Interview one-liner for mobile-first

Answer:

“In Tailwind, default styles apply to mobile, and breakpoint-prefixed styles apply to larger screens.”
